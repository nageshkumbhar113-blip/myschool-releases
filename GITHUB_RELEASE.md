# How to Release Update

## First Time (v1.0.0):
1. Go to: https://github.com/nageshkumbhar113-blip/myschool-releases/releases
2. Click "Create a new release"
3. Tag: v1.0.0
4. Title: MY_School App v1.0.0
5. Upload: release/school/MY_School-App-Setup.exe
6. Click "Publish Release"

## Next Updates:
1. Make code changes
2. Update version in package.json:
   "version": "1.0.1"
3. npm run build
4. npm run build:school
5. GitHub → New Release → v1.0.1
6. Upload new EXE
7. Publish
8. Schools get auto update! ✅
